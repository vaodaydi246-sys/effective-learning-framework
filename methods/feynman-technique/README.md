# 🧠 The Feynman Technique (Học bằng cách dạy lại)

Phương pháp tối ưu để kiểm tra mức độ hiểu sâu của bạn về một vấn đề:
1. **Chọn chủ đề:** Chọn một khái niệm bạn muốn hiểu (ví dụ: Công thức Động lượng, Cấu trúc câu điều kiện).
2. **Dạy lại cho một đứa trẻ:** Giải thích khái niệm đó bằng ngôn ngữ đơn giản nhất có thể. Không dùng thuật ngữ phức tạp.
3. **Vá lỗ hổng kiến thức:** Khi bạn bị "khựng" lại ở đâu, đó chính là nơi bạn chưa hiểu rõ. Hãy mở sách ra đọc lại phần đó.
4. **Đơn giản hóa & Hệ thống lại:** Sử dụng các hình ảnh ẩn dụ (analogy) để kết nối kiến thức.
