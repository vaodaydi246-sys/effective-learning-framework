# 📚 Effective Learning Framework (ELF)

[![GitHub License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

Chào mừng bạn đến với **Effective Learning Framework** — Dự án mã nguồn mở tổng hợp và hệ thống hóa các phương pháp học tập dựa trên khoa học não bộ (Neuroscience). 

Mục tiêu của dự án này là giúp học sinh, sinh viên tối ưu hóa thời gian, tăng khả năng tập trung sâu (Deep Work) và ghi nhớ kiến thức vĩnh viễn.
